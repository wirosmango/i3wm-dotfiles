# **Dependencies**
```
 i3wm, picom, rofi, dunst, fastfetch, polybar, feh, flameshot, kitty, thunar, ttf-jetbrains-mono, rofi-greenclip (AUR)
```

# **Installation**
```
git clone https://github.com/wirosmango/i3wm-dotfiles.git
cd i3wm-dofiles
chmod +x install-i3.sh
./install-i3.sh
```
**Done!**
