# **Dependencies**
```
 i3wm, picom, rofi, dunst, fastfetch, i3status, feh, flameshot, kitty, thunar, ttf-jetbrains-mono
```

# **Installation**
```
git clone https://github.com/wirosmango/i3wm-dotfiles.git
cd i3wm-dofiles
cp -r * ~/.config
chmod +x ~/.config/i3/poweroff.sh
```
**Done!**
