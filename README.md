# **Dependencies**
```
 i3wm, picom, rofi, dunst, fastfetch, polybar, feh, flameshot, kitty, thunar, ttf-jetbrains-mono
```

# **Installation**
```
git clone https://github.com/wirosmango/i3wm-dotfiles.git
cd i3wm-dofiles
cp -r * ~/.config
chmod +x ~/.config/polybar/launch.sh
```
**Done!**
